# API reference

Generated by `tools/docs/gen_api_docs.py` from the sources; do not edit. Every function also serves `GET /health/live`, `GET /health/ready` and `GET /metrics`. The request and response bodies are the OpenAPI schemas of the TS named per function (pinned under `docs/specs`); errors are `application/problem+json` (TS 29.500 5.2.7). With the cluster defaults every request needs the NRF's access token (Authorization: Bearer) for the service it addresses and a client certificate (mutual TLS); the admin and northbound APIs have their own authentication (below).
