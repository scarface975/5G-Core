## What is implemented from standards that may carry essential patents
The product implements 3GPP Release 16 interfaces (NGAP, NAS, PFCP, GTP-U, the service based APIs) clean-room from the published specifications. Standards bodies' IPR policies (3GPP follows the ETSI IPR
policy: members commit to license essential patents on FRAND terms) mean an implementer may need licences from holders of essential patents for the standard-compliant function; that cannot be avoided
by how the code is written. Areas where the specifications themselves call for third-party algorithms or technology:

| Area | What the product uses | Notes for counsel |
|---|---|---|
| 5G-AKA authentication | Milenage (TS 35.206), public specification, vectors of TS 35.208 | published by 3GPP for open use; check the SAGE licence text of the document set |
| NAS / AS ciphering and integrity | NEA0 / NIA0 (null), NEA2 / NIA2 (AES, from OpenSSL) | AES is a public standard; OpenSSL is Apache-2.0 |
| NEA1 / NIA1 (SNOW 3G), NEA3 / NIA3 (ZUC) | **not implemented and not offered to the UE** | the documents are restricted (ETSI SAGE) and need a licence: `docs/legal/SNOW3G-licensing.md`; the product works without them, a UE that offers only these is rejected |
| SUCI concealment | ECIES with X25519 / P-256 (TS 33.501 Annex C) | standard cryptography from OpenSSL |
| Media codecs, voice (IMS) | none (no user-plane media handling) | outside the product |
| HTTP/2, TLS, JSON | nghttp2, OpenSSL, own JSON | permissive licences, no patent grants asked |

## Third-party code
Only permissively licensed libraries are linked (OpenSSL Apache-2.0, nghttp2 MIT, libuv MIT, libpq PostgreSQL licence), dynamically; `docs/legal/audit-<version>.md` is generated at every release.
Open5GS (AGPL-3.0), UERANSIM (GPL-3.0), srsRAN / OCUDU and MongoDB are used for interoperability testing on the developers' machines only; their code is not in the product, not linked and not
distributed, and the product was written without copying from them (differences are documented by diff tools that compare behaviour on the wire, not code).
